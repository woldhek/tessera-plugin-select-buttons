# Changelog

## 0.1.1
- A new example in the README, the tile's description and the picture on the Plugins page. Nothing changes on the
  screen.

## 0.1.0
- First version: a key for each option of an `input_select` or `select` (up to six), the current option lit.
- The keys follow Home Assistant: an option chosen elsewhere lights up on the screen too.
- Optional icons per key, the tile's name above the keys, and "Tap twice to switch" against switching by accident.
